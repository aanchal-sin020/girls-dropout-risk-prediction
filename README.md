# AI System for Predicting Girls' School Dropout Risk

This project builds a machine learning system to predict dropout risk among school-going girls based on socio-economic and educational factors.

## Features
- Logistic Regression and Random Forest models
- SHAP Explainability
- Early Warning System
- Policy Recommendation Engine
- Interactive Streamlit Dashboard

## Key Risk Factors
- Household income
- Distance to school
- Menstrual hygiene access
- Early marriage risk
- Household work burden

## Technologies Used
- Python
- Scikit-learn
- SHAP
- Streamlit
- Pandas & NumPy

## Dashboard

The Streamlit dashboard allows users to input student details and estimate dropout risk along with recommended interventions.

## Ethical Note
The dataset used in this project is synthetic and does not represent real student records.
